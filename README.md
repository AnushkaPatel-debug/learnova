# ✨ Learnova

A modern futuristic EdTech landing page built using Next.js, Tailwind CSS and Framer Motion.

---

## 🚀 Features

- Responsive Design
- Animated Hero Section
- Typing Animation
- Floating Particles
- Smooth Scrolling
- Glassmorphism UI
- Interactive FAQ
- Hover Animations
- Modern Navbar
- Premium UI/UX

---

## 🛠️ Tech Stack

- Next.js
- React
- Tailwind CSS
- Framer Motion
- Lucide React
- Lenis

---

## 📱 Responsive

Optimized for:
- Mobile
- Tablet
- Desktop

---

## ⚡ Installation

```bash
npm install
npm run dev
```
